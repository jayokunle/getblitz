GetBlitz has shut down

The hosted GetBlitz service (app.getblitz.io) was discontinued on 19 November 2026. The dashboard, payment pages, API, checkout widget, webhooks and the WordPress plugin connection no longer work.

Merchants

Please remove the GetBlitz payment option or plugin from your shop and switch to another payment provider. Account data has been deleted as announced. If you have questions, email hello@jayokunle.com.

Self-hosting

GetBlitz is MIT-licensed open-source software. The source code and documentation remain available, and you can run it on your own server: github.com/jayokunle/getblitz
